# Sadaf Turkani — Personal Portfolio

**Oasis Infobyte Internship — Web Development & Designing**
Level 1 — Task 2: Personal Portfolio

A responsive, dark-themed personal portfolio built with plain HTML, CSS and JavaScript.

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## Features
- Responsive design (320px → 1440px+)
- Sticky glass navigation that changes on scroll
- Smooth scrolling and active-section highlighting
- Mobile hamburger navigation
- Skills section with honest skill levels
- Projects section rendered from a JavaScript array
- Project details modal (keyboard + mobile friendly)
- Contact form validation with success message (frontend demo)
- Scroll reveal animations with IntersectionObserver
- Back-to-top button, ripple and hover effects
- Respects `prefers-reduced-motion`

## How to Run Locally
1. Download or clone this repository.
2. Open `index.html` in any modern browser.
   (Optional: use the VS Code "Live Server" extension for auto-reload.)

## Project Structure
```
/
├── index.html   # Page structure and content
├── style.css    # Design tokens, layout, animations, responsive rules
├── script.js    # Menu, scroll effects, modal, form validation
├── README.md
└── assets/      # Images and other media
```
