# EduNova — Programming & Technology Learning Platform

EduNova is a modern and responsive landing page for a fictional online learning platform focused on programming and technology education.

This project was created as part of the **Oasis Infobyte Web Development & Designing Internship — Level 1, Task 1: Landing Page**.

## 🌐 Live Demo

Add your live demo link here after deployment.

## 📌 Project Overview

EduNova is designed to provide students and beginners with an attractive and simple introduction to programming and technology learning.

The landing page focuses on clear content structure, modern visual design, responsive layouts, and an easy-to-use navigation experience.

## ✨ Features

- Responsive navigation bar
- Hero section with clear call-to-action buttons
- Featured courses section
- Web Development course
- UI/UX Design course
- Artificial Intelligence course
- Why Learn With EduNova section
- Three-step learning journey
- Final call-to-action section
- Responsive footer
- Smooth hover effects
- Subtle CSS animations
- Responsive design for desktop, tablet, and mobile devices
- Accessible image alternative text
- Semantic HTML structure

## 📚 Learning Paths

EduNova currently presents three main learning paths:

### Web Development
Learn HTML, CSS, and JavaScript while building websites and practical projects.

### UI/UX Design
Learn how to design modern and user-friendly digital experiences.

### Artificial Intelligence
Discover the fundamentals of intelligent technologies and how AI works.

## 📱 Responsive Design

The landing page is designed to work across different screen sizes:

- Desktop
- Tablet
- Mobile

The layout automatically adapts to smaller screens using CSS media queries.
